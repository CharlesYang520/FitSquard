# FitSquad 瘦身战队 · Mockup 提示词

> 版本 v0.7 ｜ 本文数值与规则已与 `01-PRD-MVP.md`（PRD v0.7）对齐；v0.7 新增的页面元素见文末「v0.7 补充提示词」。视觉基调见第 2 节（深色 Tesla 式极简 + 潮玩），文案语气与红线见第 6 节。设计基准另见 `docs/.agents/tasks/v06-design-baseline.md`。

## 1. 使用说明

1. 先把第 2 节「全局设计规范」整段粘贴进工具（Figma Make、MasterGo AI、Motiff、v0、Uizard、即时设计均可），作为风格基准或 Style Guide。英文效果更好的工具（v0、Uizard）改用第 4 节英文版。
2. 再逐页粘贴第 3 节页面提示词，一次一个页面。每段都自包含关键风格词，单独粘贴也能用。
3. 画板统一 375×812（iPhone X/11/12 尺寸），@2x 导出。
4. 微信小程序约束：
   - 右上角固定有微信胶囊按钮（「··· | ⊙」，约 87×32，距顶 48、距右 7），任何内容不要放在这个区域。
   - 顶部使用微信原生导航栏（白底或主色底 + 居中标题 + 左侧返回），不要设计自定义顶栏、不要放与胶囊冲突的右上角按钮。
   - 底部自定义 tab 栏 4 项：首页 / 战队 / 排行 / 我的。仅一级页面（03 / 07 / 10 / 13）显示 tab 栏，二级页面不显示。
   - MVP 没有健康知识、新手引导玩法介绍页、全站战队榜 / 个人总榜、积分商城、充值积分（v0.5 已砍，相关页面归档在 `../mockup/_archived/`）。
5. 生成后先对照第 5 节检查清单，再进入细化。
6. 页面文案拿不准时，从第 6 节文案语气库里选，或按第 6.1 节红线自己写。

## 2. 全局设计规范（中文）

```
【FitSquad 瘦身战队 · 全局设计规范】
产品：微信小程序，熟人 / 同事（公司 / 部门 / 好友 / 家庭）3–10 人组队较劲的减重游戏（公司/家庭/好友战队），队伍自选周期 14/21/30/60 天，每人设定个人减重目标（kg，受健康上下限约束），每人押注 100/200/500/1000 活力值（或 0 押注“友谊赛”，只发徽章），每人同时只能参加 1 支战队，周期结束按达成情况结算：全员达成每人退回押注 + 系统奖励 + 全员加成，拿得最多；部分达成时达成者从奖池分成（每人最多半份押注）+ 一半系统奖励。积分只有活力值（赚来的），只用于押注与结算，外加徽章 / 称号荣誉；不能兑换现金、不能转让，12 个月有效；MVP 没有积分商城和充值积分。新人注册送 1000 活力值。好胜心玩法：队内周称号、被好友反超时的超越提醒、调侃表情、建队时选填的线下趣味惩罚。
目标用户：25–40 岁职场人，和同事、好友、家人组队。
品牌个性：活力、潮、有点好胜、不说教。像一个"熟人之间互相盯梢、互相嘲"的小游戏，不像医院或健身房。

设计基调（v0.6 · 深色 Tesla 式极简 + 潮玩点睛）：深色底 + 暖色点睛，大量留白，一屏一主角（最重要的东西——连胜数字 / 奖励结果——大到夸张，其余退后），无描边卡片（靠留白和深浅色块分隔），一屏一个主按钮，次要信息靠上滑揭示。潮玩的"皮"用盲盒小人 / 礼盒作为大片留白中的精致主体（像 Tesla App 里那辆车），不铺满。

画板：375×812，iPhone 尺寸。顶部为微信原生导航栏（深色底白字），右上角预留微信胶囊按钮区域（约 87×32），不放任何内容；不做自定义顶栏。

配色（深色主题）：
- 主背景 近黑紫 #17141F → #241B33（渐变）
- 深色卡片 / 信息块 #2E2440；次级块 / 按钮底 #3A2E52
- 主点睛橙 #FF7A3D；点睛粉 #FF4D8D；主渐变 #FF4D8D → #FF8A3D（主 CTA / 主数字，135°/90°）
- 高亮黄 #FFD84D（连胜火苗、奖励、段位感）
- 成功 薄荷绿 #22D3A6（达成、打卡完成）
- 失败 柔红 #FF5C7A（未达成，柔和不刺眼）
- 文字：主 #FFFFFF、次要 #8A7FA6（柔紫灰）、最弱 #6A5F85；分割 #3A2E52
- 阴影在深色下改为暖色径向发光（glow），不用灰投影

字号层级（PingFang SC，层级拉开）：
- 一屏主角超大数字 72–96 Bold（连胜天数、奖励主数字，用 DIN/等宽数字字体）
- 大数字 40 Bold / H1 24 Bold / H2 17 Semibold / H3 16 Medium
- 正文 14 Regular，行高 1.5 / 辅助 13 / 次要说明用柔紫灰 / 标签 11 Medium
- 文案克制：一个信息块最多一句主文 + 一句副文

圆角：卡片 24、按钮 34（更胶囊、更潮玩）、输入框 14、标签 999、头像圆形。
间距：页面左右边距 16，大量留白，8 的倍数栅格。
卡片：深色 surface，无描边；主角元素用暖色发光 glow；重点卡片用主渐变底 + 白字。
按钮：主按钮 高 48–64、主渐变、白字、发光；一屏只一个最显眼的主按钮；次按钮深色 surface + 橙描边。
图标：线性圆角图标，2px 线宽，端点圆头，选中态填充主色。
插画：扁平潮玩盲盒小人（大头圆身、点状眼、半透明腮红、配色取黄 / 粉 / 薄荷 / 紫），领先态发光、摸鱼态变灰 + 红感叹号；大片留白中一个精致主体；不出现真人照片、不出现身材焦虑暗示（不画“胖瘦对比”）。
数据隐私：默认展示减重百分比（如 -3.2%）；具体公斤数默认仅本人可见（标“🔒 仅自己可见”），队友之间显示减重 % 和目标 %，本人可在隐私设置里开启“向队友显示具体体重”；排行榜、海报、邀请页等对外页面只显示百分比。
文案语气：诙谐、搞怪、互相调侃，激发好胜心；口语、短句，可用 emoji，例如“今天也别掉队”“小王又偷偷瘦了”“就这？”“我先瘦为敬”；不说教、不用“必须”“严禁”。文案红线：只调侃行为（偷吃、摸鱼、熬夜、赖床、嘴硬、不打卡）；绝不调侃体型、体重数字、长相、性别、年龄、健康状况；失败时自嘲 + 约复仇，不羞辱；不鼓励极端节食；调侃是友好较劲，不是羞辱。
免责：涉及目标和健康的页面常驻“本产品不提供医疗建议，有基础疾病请先咨询医生”；押注挑战前有免责勾选“孕期/哺乳期、有进食障碍史、有基础疾病者不建议参加押注挑战”。
称重标准：打卡相关页面提示“晨起、空腹、如厕后、轻衣、同一台秤”。
底部 tab 栏（仅一级页面）：白底，高 56 + 安全区，4 项“首页 / 战队 / 排行 / 我的”，线性图标 + 12 号文字，选中主色 #FF6B35，未选中 #9CA3AF。
```

## 3. 页面提示词

### 3.1 启动登录页

```
【FitSquad 瘦身战队 · 启动登录页】
风格：活力、轻松、有点好胜；主色活力橙 #FF6B35 → 珊瑚 #FF8A80 渐变；扁平卡通战队小人插画；375×812 微信小程序，右上角预留胶囊按钮区，无底部 tab 栏。
页面目标：让新用户 3 秒内明白“组队减重赢积分”，并一键手机号授权登录。

布局（从上到下）：
1. 全屏品牌渐变背景，上部 55% 区域为插画：3 个卡通小人（穿运动服）手搭手喊口号，背景有奖杯和积分金币飘浮。

4. 白色圆角底部面板（圆角 24，覆盖下部 35%）：
   - 主按钮“微信手机号一键登录”（品牌渐变，高 48，带微信图标）
   - 次文字链接“暂不登录，先逛逛”（#9CA3AF）
   - 协议勾选行：圆形勾选框 + “我已阅读并同意《用户协议》《隐私政策》《健康免责声明》”，书名号内为主色链接
```

### 3.2 身体档案（登录后第一屏）

```
【FitSquad 瘦身战队 · 身体档案】
风格：活力、轻松、不说教；白底 #FFFFFF，主色活力橙 #FF6B35，成功绿 #22C55E；扁平卡通战队小人插画；375×812 微信小程序，原生导航栏标题“身体档案”+ 返回，右上角预留胶囊按钮区，无底部 tab 栏。

- 顶部一句轻引导：“填好档案，领 1000 活力值，开始组队较劲”（不做多屏玩法介绍）。
```

### 3.4 创建战队（2 步）

```
【FitSquad 瘦身战队 · 创建战队 2 步】
风格：活力、轻松；白底卡片圆角 16、背景 #F7F8FA；主色活力橙 #FF6B35；选中态橙色描边 + 浅橙底 #FFE8DE；375×812 微信小程序，原生导航栏标题“创建战队”+ 返回，右上角预留胶囊按钮区，无底部 tab 栏。请输出 2 张画板。
通用：顶部步骤条“① 基本信息 ② 规则契约”，当前步为橙色；底部固定主按钮。第 2 步“下一步”进「设定个人目标」页（3.6）的队长发起状态收尾并发起契约，所以本页不再有单独的第 3 步。

第 1 步 · 基本信息（精简，只留必填）
- 战队名称输入框，提示文字“给战队起个响亮的名字”，示例填入“鹅厂 3 楼减脂突击队”，右下角字数“9/16”
- 战队类型三选一卡片（带图标）：公司 / 家庭 / 好友，选中“公司”；选公司时出现“公司名（选填）”输入框（公司名是通往企业版的桥，保留）
- 队徽：默认给一个 🔥，右侧小“换一个”链接可点开 6 宫格修改（不再是必选的大区块）
- 战队口号（选填，默认折叠）：点“+ 加个口号”展开，示例“少吃一口，多赢一份”
- 按钮“下一步”

第 2 步 · 规则契约
- 挑战周期（队伍自选）：四个胶囊按钮 14 天 / 21 天 / 30 天 / 60 天，选中“30 天”
- 每人押注（活力值）：五个胶囊 0 友谊赛 / 100 / 200 / 500 / 1000，选中“200”；下方灰字“全队统一押注，队长定；只能用赚来的活力值押注”；选中“0 友谊赛”时下方显示“不进奖池、没有系统奖励积分，只发徽章，适合先和家人朋友试试”
- 人数上限：步进器“3–10 人”，当前“5 人”；提示“至少 3 人才能开赛”
- 开赛说明行：“全员确认即开赛；48 小时截止时已确认满 3 人自动开赛，没确认的自动移出、押注退回；不满 3 人自动解散，押注退回。开赛后不能再加人”
- 结算规则说明卡（浅灰底，可折叠）：
  · 全员达成：退回押注 + 系统奖励（14 天 100 / 21 天 150 / 30 天 200 / 60 天 400）+ 全员加成（押注的 50%）+“铁血战队”徽章
```

## 6. 文案规范与文案语气库

### 6.1 文案规范（与 PRD 4.13 一致）

语气：诙谐、搞怪、互相调侃，激发好胜心。目标是让大家通过好友排名、组队较劲，一起把体重和健康管住。

| 红线 | 怎么做 |
|---|---|
| 只调侃行为 | 偷吃、摸鱼、熬夜、赖床、嘴硬、不打卡 |
| 绝不调侃身体 | 不拿体型、体重数字、长相、性别、年龄、健康状况开玩笑；文案里不出现具体 kg |
| 失败不羞辱 | 自嘲 + 约复仇，不点名嘲笑失败者 |
| 不鼓励极端节食 | 不写「宁可挨饿也要瘦」「不吃晚饭」这类话，改成"吃对""少吃一口""多走两步" |
| 友好较劲 | 被调侃的人看了会笑、想回嘴，而不是难受；emoji 随便用 |
