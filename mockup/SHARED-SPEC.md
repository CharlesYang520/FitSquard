# FitSquad Mockup · 共享约定 · v0.9

数值以 `docs/01-PRD-MVP.md`（v0.9）为准；两者冲突时 PRD 赢。v0.8 及以前的规范见 `.backup/v0.8-2026-10-24/mockup/SHARED-SPEC.md`，旧页面在 `_archived/`。

## 1. 视觉基调（主题 ③ 碳白竞技，v0.9 最终）
简单、醒目、有竞技感。
- 页面底 `#FAFAF8`，卡片纯白 `#FFFFFF` + 1px 细线 `#EEECE7`，不用阴影或只用极轻阴影。
- 碳黑 `#141414`：主文字、主按钮（黑底白字）、黑色头部（战队 / 战书 / 战报 / 海报 / AI 推荐卡）、贴满的槽。
- 信号橙 `#FF5A1F`（浅底文字用 `#E2480F`，浅橙底 `#FFF1EA`）：只给 AI 推荐标签、推荐卡打勾、主角数字（“再做 1 项”“4 天”“6”）、当前 tab、按住确认的填充，**每屏 ≤ 2 处**。
- 大数字用衬线体（`--font-serif`：New York / 宋体；真机用 loadFontFace 加载一款授权衬线字体）。
- 不用粗描边、硬投影、倾斜贴纸、荧光色、渐变。人物头像色降饱和（陶土、墨绿、灰紫等），不与信号橙冲突。
- 旧主题（深紫 v0.6、奶油荧光绿 v0.8、森林预览）已全部被 `style.css` 第 19 节覆盖；三套主题对比预览在 `mockup/theme-preview/`。

## 2. 技术约束
- 纯 HTML + `../assets/style.css` + 可选 `../assets/mock.js`，双击即可打开；不引 CDN、Web 字体、外链图片；插画只用内联 SVG / emoji。
- 页面私有样式只放布局微调；颜色、圆角、字号一律用变量和类。
- 页面骨架（`mk-desk` → `mk-header` → `stage` → `device` → `phone` → `topbar` / `screen` / `bottom-bar` / `tabbar`）沿用旧版，右上角胶囊区每页必带、区域内不放内容。
- 一级页（03 今日 / 07 战队 / 13 我的）显示 3 个 tab：`<nav class="tabbar tabbar--3">`，链接固定为 `03-home.html` / `07-team-home.html` / `13-me.html`。
- 多状态：`.phone` 上 `id` + `data-state`，子元素 `data-when`，手机框外 `.mk-switch` 按钮 `data-set-state` + `data-target`。

## 4. 规范口径（唯一）
- **没有积分**：任何页面不得出现积分、活力值、押注、奖池、冻结、到账、兑换、提现。
- **没有身体档案**：登录只有“微信一键登录”；加入只有“接下战书”；身高体重只在 13 我的“记一下体重”里出现，首次单独勾选同意（不默认勾选）。
- **体重永不公开**：kg 只出现在 13 我的的私密体重卡；排名、战报、海报、动态、战书都不出现 kg 或减重 %。
- 周期只有 14 天（默认）/ 21 天；主题：综合 / 多走动 / 吃好点 / 早点睡。
- 每天 9 项清单（🏃 动一动 / 🥗 吃喝 / 🌙 作息），其中 1 项标“AI 推荐”；**任选 3 项完成 = 当天达标**。今天状态：正常 / 很忙（只显示 5 分钟内的）/ 不太舒服（只显示恢复类，1 项即达标，每局最多 2 天）。达标后多做的只算“额外完成”。
- 工作日 / 休息日：系统按节假日日历判断；工作日标签黑底“💼 周四 · 工作日”，休息日荧光绿“☀️ 周六 · 休息日”。工作日侧重防久坐、饭后走、午休；休息日侧重出门 30 分钟、8000 步、约人一起动、少外卖、别熬夜补觉。
- 打卡页结构：日期标签 + 标题 → 今天状态 → 3 个贴纸槽 → AI 推荐卡（只推 1 项 + 一句理由）→ 剩余清单（已完成的不重复）。打卡 = 圆形打勾 → 确认弹层 → **按住 1 秒**确认。
- 点“做完了”必弹确认：“真的做完了？这条会发到队内动态……”；步数类任务微信运动自动核验；带时间的任务到点才能点。
- 开局即开始（当天 Day 1），1 人可开，最多 10 人，局内随时加入，从加入当天算。
- 排名按达标率（达标天数 / 加入后天数），并列看连续达标，再看本局完成项数（每天最多计 3 项）。
- 表情只有 💪 / 就这？ / 你礼貌吗。
- 本局称号只在战报出现：全勤王 / 最稳 / 早鸟 / 压哨王 / 摸鱼选手，每人最多 1 个。
- 催一下：主按钮“直接提醒他”（系统发微信服务通知）；对方没通知额度时换成“发到微信”分享今日战况卡（今日 N/M + 全队连续达标 + “@某人 就差你了”）。每人每天最多催 3 次。
- 提醒：没有单独的“订阅提醒”按钮，点“我做完了”时顺手授权 3 种通知，完成页显示一行“🔔 已帮你订好明早的微信提醒”。
- 排名是实时的（点完“我做完了”立即刷新）：首页一行“实时排名：你第 3”，战队页“实时排名 LIVE”，打卡完成反馈也显示名次。
- 免责：登录页、开一局、战书落地页、打卡页、首页、我的页有“不适即停 / 有基础疾病请先咨询医生”。
