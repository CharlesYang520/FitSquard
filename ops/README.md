# FitSquad 瘦身战队 · Agent 运营小队

一人公司运营手册：Agent 负责出草稿和给建议，人负责审核和执行。每天人工投入约 30 分钟。

> 已与 `docs/01-PRD-MVP.md`（PRD v0.9）和 `docs/02-整体解决方案.md`（v0.9）对齐，冲突时以 PRD 为准。v0.8 及以前（积分押注版）的运营手册见 `.backup/v0.8-2026-10-24/ops/`。

## 分阶段启用
| 阶段 | 启用 Agent | 触发条件 |
|---|---|---|
| 种子期 | 内容官、数据官、风控官 | 上线即用 |
| 增长期 | + 活动官、用户运营官 | 注册用户 > 1000 |
| 企业期 | + 商务官 | 出现企业线索 |

种子期没有用户运营官：活动、触达、组队撮合由人直接在种子群里做，依据是数据官每天的「流失预警名单」。MVP 唯一核心假设是留存 + 自发裂变，按名单捞人是种子期最重要的人工动作。

## 产品事实（PRD v0.9）
- 玩法：熟人 1–10 人开一局 **14 天（默认）/ 21 天**；开局当天就是 Day 1，一个人也能开，局内随时能通过战书加入，从加入当天开始算。每人同时只在 1 支进行中的战队。
- 计划：全队共用一套 AI 清单，每天 9 项，其中至少 4 项 5 分钟以内、2 项随时可做；每 7 天一天以恢复类为主。分工作日 / 休息日两套侧重（按节假日日历自动判断）：工作日防久坐、饭后走、午休、早睡；休息日出门走 30 分钟、8000 步、约人一起动、少外卖、别熬夜补觉。AI 只从人工审核过的行动模板库里挑选、排序、改写文案；主题：综合 / 多走动 / 吃好点 / 早点睡。
- 打卡：每天一张 9 项清单（动一动 / 吃喝 / 作息），任选 3 项完成 = 当天达标；今天状态可选“很忙”（只看 5 分钟的项）或“不太舒服”（恢复类 1 项即达标，每局最多 2 天）；每次点都弹“真的做完了？”确认；步数类微信运动自动核验；带时间的项到点才能点；不支持补卡。
- 竞争：全队连续达标（全员都做完才 +1，一人没做就清零）；个人连续达标；队内排名按达标率（达标天数 / 加入后天数），并列看连续达标，再看完成项数（每天最多计 3 项），并列看连续达标，再看“第一个完成”次数。
- 互动：催一下 = 今日战况卡（“4/5 做完了，@大刘 就差你了”），只有一个“发到微信”按钮，每人每天最多 3 次；排名实时刷新；表情只有 💪 / 就这？ / 你礼貌吗。
- 结束：自动生成战报（完成率、连续达标、名次、本局称号：全勤王 / 最稳 / 早鸟 / 压哨王 / 摸鱼选手）；唯一主按钮“再来一局”，周期默认升到 21 天。
- 邀请：战书（“XX 向你下了战书”+ 一句狠话）。
- 体重：本人可选的私密记录，不进排名、战报、海报。
- **没有积分、活力值、押注、奖池、结算金额；没有身体档案、手机号绑定、起始 / 终点称重。** 不要在任何运营内容里提到这些。
- 提醒：微信服务通知。点“我做完了”时顺手授权明早提醒 / 被队友催 / 全员到齐三种通知；催一下优先直接发通知，对方没额度时才用“发到微信”的战况卡兜底。完全不打开的人只能靠群里催或人工私聊。
- 目标用户：25–40 岁职场人及亲友；种子期以同事 / 好友组队为主。

## 目录结构
```
ops/
├── README.md          本文件
├── agents/            6 个 Agent 的角色说明（提示词 / SOP，按阶段启用）
├── inbox/             人工放入的脱敏数据（按日期分子目录）
├── drafts/            Agent 产出的草稿（按日期分子目录）
└── published/         人工审核通过、已执行 / 已发布的归档
```

## 每天约 30 分钟
| 时间 | 步骤 | 动作 |
|---|---|---|
| 0–5 分 | 导出 | 后台导出前一日数据，脱敏后放入 `ops/inbox/YYYY-MM-DD/` |
| 5–10 分 | 运行 | 按顺序跑已启用的 Agent：数据官 → 风控官 →（增长期）用户运营官 → 活动官 → 内容官 →（企业期，每周一、四）商务官 |
| 10–12 分 | 产出 | 写入 `ops/drafts/YYYY-MM-DD/<agent>-<类型>.md` |
| 12–27 分 | 审核 + 捞人 | 先看风控，再按流失预警名单在种子群 / 私聊逐个跟进，最后审内容 |
| 27–30 分 | 归档 | 通过的移入 `ops/published/YYYY-MM-DD/` 并执行，文件头补 `状态: 已执行 / 执行人 / 时间` |

## 全员红线
1. 不做医疗宣称（不说“治疗”“根治”“药效”“保证瘦 X 斤”）；涉及健康建议统一加“仅供参考，身体不适请就医”。
2. 不提积分、押注、奖池、提现、兑换、现金或实物奖励（品牌赞助局的线下奖品由赞助方发放，需人工单独审批）。
3. Agent 不直接改数据库、账号状态，不封号，只输出建议。
4. 只读 `ops/inbox` 脱敏数据，不推断真实身份。
5. 不鼓励节食、断食、催吐、脱水、过量运动；行动模板只能是轻 / 中强度。
6. 文案红线（PRD 4.8）：只调侃行为（摸鱼、不打卡、嘴硬、熬夜），绝不调侃体型、体重、长相、性别、年龄、健康状况；失败只自嘲 + 约下一局；文案里不出现 kg。
