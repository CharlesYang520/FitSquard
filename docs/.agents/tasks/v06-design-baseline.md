# FitSquad v0.6 设计基准 —— 深色 Tesla 式极简 + 潮玩点睛

> 本文件是 v0.6 改造的唯一视觉 / 交互依据。用户已确认方向。改造包含：① 新视觉系统（深色潮玩，替换现有白+橙）；② 降门槛的交互流程；③ 新留存玩法（连胜 / 社交钩子 / 盲盒奖励）；④ 四份文档对齐。

## 0. 一句话产品灵魂
不是减肥 App，是「熟人之间每天互相盯梢、互相嘲」的小游戏。瘾点在"我在这群人里排第几 + 有人在看我"，不在"我瘦了多少"。

## 1. 设计哲学（Tesla 式）
- **一屏一主角**：每屏只有一个最大的视觉焦点，其余靠上滑揭示，不摊开。
- **极致留白**：信息块之间大量留白，不塞满。
- **层级极端**：最重要的（连胜数字、奖励结果）大到夸张；次要的小到退后。
- **配色克制**：深底 + 一个暖色点睛渐变，不撞色堆砌。
- **无描边卡片**：靠留白 + 深浅色块分隔，不用边框线。
- **一屏一主按钮**：主要动作只有一个，最显眼。
- **潮玩的皮**：盲盒小人 / 礼盒作为"大片留白中的精致主体"出现（像 Tesla App 里那辆车），不铺满。

## 2. 视觉系统（替换 style.css :root）
深色主题。保留现有类名结构，只换配色变量和新增深色类，尽量不破坏已有布局类。

| 变量 | 新值 | 用途 |

| `--c-ink-2` | #241B33 | 背景渐变终点 / 次级深底 |

| `--g-hot` | linear-gradient(90deg,#FF4D8D,#FF8A3D) | 主 CTA / 主数字 |

### 2.2 字体层级（放大、拉开）
| token | 值 | 用途 |
|---|---|---|
| 超大数字 | 72–96px 800 | 连胜天数、奖励主数字（一屏主角） |
| H1 | 24px 800 | 页面主标题 |
| H2 | 17px 700 | 卡片 / 块标题 |
| body | 14px | 正文（尽量少） |
| dim | 13px 500 | 次要说明，用 `--c-text-dim` |
数字用等宽数字字体栈。文案克制：一个信息块最多一句主文 + 一句副文。

### 2.3 形状 / 阴影
- 圆角更大：卡片 24px，按钮 34px（更胶囊、更潮玩）。
- 阴影在深色下改为"发光"：主角元素用径向暖光 glow，不用灰色投影。
- 盲盒小人规范：大头圆身、点状眼、半透明腮红、配色取 `--c-gold`/`--c-pink`/`--c-mint`/紫；领先态发光、摸鱼态变灰 + 红感叹号。

### 2.4 微信约束不变
右上角胶囊区留空；原生导航栏（深色 topbar）；一级页底部 4 tab（首页/战队/排行/我的），深色底。

## 3. 留存三件套（只做这三个，其余砍）
1. **连胜 Streak**：`users` 增 `streak_days`、`streak_best`。连续有效打卡日 +1，断一天清零。首页主角就是这个大数字。断签前给一次挽回提醒。这是第一留存杀器。
2. **社交钩子（每天一条）**：首页 / 战队主页只给一条最扎心的——"被谁反超"或"谁在群里 @你"。一条，不是一堆。一个动作按钮（回怼 / 去打卡）。复用现有 R-07 超越提醒 + 催一下逻辑，收敛成"每天一条"。
3. **盲盒式可变奖励**：打卡成功页不再是干巴巴 +5，而是开出一个"有变化"的结果：连胜+1 / 排名反超 / 抽到盲盒表情 / 随机鼓励。像拆盲盒，每天不同，期待下一次。奖励是纯虚拟（表情、称号、连胜里程碑），不碰积分经济红线。

**明确砍掉（太费脑，违背"不动脑"）**：段位、赛季进度、战队 PK 血条。留作 V1.1 深度玩法，v0.6 不做。

## 4. 降门槛的流程改造（上手 30 秒、点 3 下）
1. **先逛再组队**：登录后（或"先逛逛"）首页默认展示一个"热闹现场"——示例战队的动态流 + 好友排行片段 + 互相调侃，让新用户先感到"这里有人在玩、在斗嘴"，再引导加入 / 创建。不再是空荡荡逼你立刻建队。
2. **档案延后**：登录后不强制先填身体档案。想打卡 / 设目标 / 加入押注战队时再填（档案页保留，但从"登录后第一屏"降级为"按需触发"）。健康数据单独同意、免责勾选在填写时仍然保留（合规不动）。
3. **一屏一动作**：每个一级页只留一个主按钮。首页=打卡（有队时）/ 看热闹→加入（无队时）。
4. **打卡零思考**：打开直接相机，拍一下完成；体重数字、类型等折叠为次要。拍完立刻进"盲盒奖励"爽点页。
5. **成团门槛**：3 人起团保留（这是熟人社交的根），但支持 **0 押注友谊赛作为默认试玩档**，让第一次几乎零门槛；不降到 2 人（2 人没有"排行"的较劲感）。

## 6. 不变的硬约束（不许动）
- 结算数字：全员 500 / 部分达成者 400 / 坚持奖 60；奖池 340 / 回收 40；小王 1,658 / 1,458 / 200；系统奖励 R；周期；人数 3–10；押注档位；目标上下限。
- 合规：健康数据单独同意、免责勾选、积分不可兑现/转让、12 个月有效、不调侃身体（4.13 文案红线）。
- 积分只有活力值，纯虚拟荣誉出口；无商城、无充值（v0.4/v0.5 已定）。
- 排行只有好友榜；每人同时 1 支战队；无健康知识、无新手引导玩法介绍页、无中期加码、无全站战队榜（v0.5 已定）。
- 微信约束：胶囊区留空、原生导航、tab 只在 4 个一级页。
- 纯本地 HTML + style.css + mock.js，无 CDN / Web 字体 / 外链图片；插画用内联 SVG / emoji。
