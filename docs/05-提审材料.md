## 2. 类目说明（填在类目申请 / 审核备注里）
本小程序为熟人组队的日常健康习惯打卡工具：用户与同事朋友组成战队，每天从 9 个轻量行动（散步、拉伸、多喝水、早睡等）中任选 3 个完成并打卡，查看队伍连续达标与队内排名。不提供医疗诊断、治疗、营养处方或减重承诺；不涉及任何金钱交易、下注或奖品；不开放用户发布图文内容。

## 3. 功能介绍（小程序简介，≤ 120 字）
拉上同事朋友组队，14 天一局。每天 9 个小行动任选 3 个，做完一项打一项，全队连续达标谁也不想当断的那个。没有押注、没有积分，只比谁更稳。

## 4. 审核备注（提交审核时填写）
1. 首次进入为登录页，勾选协议后点“微信一键登录”即可，无需手机号。
2. 测试路径：登录 → 首页“开一局” → 选周期主题 → “开局，今天就开始” → “先去打今天的卡” → 点任一项右侧 ✓ → 按住按钮 1 秒确认。
3. 一个人即可开局体验全部打卡流程；邀请队友通过“发到微信”分享卡片。
4. “步数类”行动需授权微信运动，仅用于判断当天步数是否达到目标。
5. “私密体重”为可选功能，需单独勾选同意，数据仅本人可见，可随时撤回删除。
6. 订阅消息仅在用户点击打卡 / 开局 / 加入时请求授权，用于打卡提醒、队友提醒、战报通知。
7. 小程序内无支付、无虚拟货币、无用户发布内容。

## 5. 常见驳回与应对
| 驳回原因 | 应对 |
|---|---|
| 类目不符 / 需要医疗资质 | 换“工具 > 健康管理”类目以外的候选；在简介和备注里强调“习惯打卡工具，不涉及医疗” |
| 社交功能需企业主体 | 确认主体是个体工商户（非个人）；说明仅限受邀熟人组队，无陌生人社交、无公开发布内容 |
| 隐私指引与实际收集不一致 | 对照本文件第 1 节和 `legal.ts` 第一节逐项勾选 |
| 诱导分享 | 分享按钮文案保持“发到微信”，不承诺分享奖励；不强制分享才能使用 |
| 订阅消息滥用 | 只在用户点击时请求；不在页面加载时弹出 |
