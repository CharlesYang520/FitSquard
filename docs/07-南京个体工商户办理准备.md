# 南京办理个体工商户 · 准备清单

> 用途：作为“瘦身战队”小程序的运营主体（认证、类目、备案、协议署名）。
> 说明：以下流程按江苏 / 南京线上登记的通行做法整理；入口名称、地址要求以办理当天页面和窗口答复为准。整理时间：2026-10-25。

## 一、办理入口（任选其一，都免费）
1. **江苏政务服务**：App / 微信小程序 / 网站，搜索“个体工商户开业登记”（经营主体登记全程电子化）。
2. **我的南京** App：政务服务 → 市场监管 → 个体工商户设立。
3. **线下**：住所所在区的政务服务中心“市场主体登记”窗口（不确定地址能不能用时，直接去窗口问最快）。

全程：填信息 → 本人刷脸签名 → 审核（一般 1–3 个工作日）→ 领**电子营业执照**（微信 / 支付宝“电子营业执照”小程序即可下载）。纸质执照可选邮寄或自取，小程序认证用电子版就够。

## 二、需要准备的
| 项目 | 内容 | 状态 |
|---|---|---|
| 经营者 | 你本人身份证（原件拍照）、本人手机号、能刷脸 | ☐ |
| 名称（字号） | 见第三节，准备 3 个备选 | ☐ |
| 组成形式 | 个人经营 | — |
| 经营场所 | 见第四节，二选一 | ☐ |
| 经营范围 | 见第五节，直接复制 | ☐ |
| 从业人数 / 资金数额 | 1 人；资金填 1 万元即可（认缴性质，不用验资） | — |
| 联系电话 / 邮箱 | 你本人的 | ☐ |

## 三、名称备选（个体户名称 = 行政区划 + 字号 + 行业 + 组织形式）
按优先级，提交时系统会自动查重：
1. 南京市**XX区**瘦身战队健康咨询服务部
2. 南京市**XX区**一起瘦信息技术服务部
3. 南京市**XX区**连续达标健康管理工作室

- “XX区”填经营场所所在的区（如鼓楼区、建邺区）。
- 名称里避免“医疗、诊所、减肥、减重”等字眼，以免被要求医疗资质。
- 个体户也可以不起字号，但小程序认证和协议署名用有字号的名称更清楚，建议起。

## 四、经营场所（二选一）
**方案 A：用住所登记（最简单，先问这个）**
- 自有房：房产证 / 不动产权证照片。
- 租的房：租赁合同 + 房东产权证明。
- 部分地区对住宅登记有限制或要求出具《住所（经营场所）申报承诺书》，提交时页面会提示；被退回就去窗口问。

**方案 B：用“网络经营场所”登记**
- 依据《网络交易监督管理办法》：电子商务经营者申请登记为个体工商户的，允许将网络经营场所作为经营场所登记。
- 需要填网店 / 小程序的名称和网址，有的窗口会要平台出具的“网络经营场所证明”。小程序还没上线时可能不好证明，所以优先用方案 A。

## 五、经营范围（复制使用；系统里按“经营范围规范表述”选同名条目）
**一般项目（不需要许可）**
- 健康咨询服务（不含诊疗服务）
- 体育健康服务
- 软件开发
- 信息技术咨询服务
- 互联网销售（除销售需要许可的商品）
- 组织体育表演活动（可选，以后做线下活动用）

**不要选**：医疗服务、诊疗、营养健康咨询中涉及处方的、食品销售（目前用不到，选了会多出许可或检查）。

## 六、拿到执照后（按顺序）
1. **税务**：线上登记后一般自动同步税务信息；首次登录“江苏税务”App / 电子税务局确认一下“个体工商户信息确认”。无收入时每月 / 每季**零申报**（一般在 App 里点几下）。不想自己报可以找代账，几十到一两百元一月。
2. **小程序**：用新邮箱注册小程序，主体选“个体工商户”，上传电子营业执照 → 管理员（你）刷脸 → 微信认证。
3. **备案**：认证通过后提交小程序备案，负责人填你本人。
4. 把**个体户全称**和**客服联系方式**发给开发（填进协议页面），并把新 AppID 发过来。

## 七、注意
- 个体户每年 1 月 1 日–6 月 30 日要做**年报**（国家企业信用信息公示系统，免费，5 分钟）。忘了会被列入经营异常。
- 没有经营收入也要按期申报税务（零申报），否则会产生罚款或影响信用。
- 不再使用时可以线上**简易注销**。
