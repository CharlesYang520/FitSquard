# 种子期运营手册（第 5 步，W6–W9）

目标（PRD §1）：3–5 支熟人队、15–25 人；每队自发带来 ≥ 1 个新成员；14 天完成率 ≥ 60%；D7 留存 ≥ 60%；结束后 7 天内再来一局 ≥ 50%。

## 1. 拉队（W6 第 1–3 天）
- **你自己先开一局**，拉 3–5 个最熟的同事，当“样板队”。
- 再找 2–4 个“队长”：每人能拉 3–6 个熟人（同部门、同小区、健身群、家人）。队长标准：自己愿意每天打卡、在群里说话有人回。
- 给队长的话术：“我在内测一个小程序，14 天一局，每天 9 个小事里挑 3 个做，比如饭后走 15 分钟、少喝一杯奶茶。没押注没积分，就是比谁不断。你拉几个人一起？”
- 开局时间：**工作日开局**（周一或周二），第一天就能碰到工作日清单；避开长假前一天。

## 2. 每天（10 分钟）
| 时间 | 做什么 | 看哪里 |
|---|---|---|
| 09:00 | 看昨天结算后的数据 | 运营后台 → 概览：今日打卡人数、北极星 |
| 12:30 | 抽检 1–2 支队明天的清单，不合适的模板下线，必要时“明天起回退兜底” | 后台 → 战队 → 计划抽检 |
| 21:00 | 看哪些队今天还没全员到齐，私聊队长“提醒一下 XX” | 后台 → 战队详情 → 成员“今天未达标” |

**不要**替用户打卡、不要在群里公开点名批评；只通过队长温和提醒。

## 3. 每周（30 分钟）
- 记录本周：北极星、D3 / D7、完成率、催一下次数、新增成员来自哪支队。
- **访谈 2–3 人**（各 10 分钟），固定问：
  1. 哪天差点断？当时为什么没断 / 断了？
  2. 9 项里你最常选哪 3 项？哪项从来不选？
  3. 你被催过吗？什么感觉？
  4. 会不会再来一局？会拉谁？
- 把“从来不选”的模板记下来，周末统一下线或改写。

## 4. 关键节点
| 节点 | 动作 |
|---|---|
| Day 1 晚上 | 私聊每个队长：今天大家都打上了吗？有没有卡住的地方（登录、头像昵称、找不到入口、打卡间隔） |
| Day 3 | D3 留存第一次能看到。掉队的人让队长单独拉一下 |
| Day 7（恢复日） | 观察“恢复日”清单是不是太轻 / 太无聊 |
| 最后一天 | 提前一天在群里预热“明天出战报，看看谁是全勤王、谁是摸鱼选手” |
| 战报日 | 队长在群里发战报海报，带一句“第二局谁来” |
| 结束后 3 天内 | 没再开局的队，私聊队长问原因 |

## 5. 什么时候改规则
- 打卡间隔（`core/scoring.ts` 的 `COOLDOWN_MIN`，现在 2 分钟）：访谈里有人抱怨“补打很麻烦”就降到 1 分钟或取消；发现有人一口气刷满再调高。
- 每天门槛 3 项：如果 D3 掉得厉害、访谈说“太多”，考虑工作日 2 项 / 休息日 3 项。
- 9 项太多挑花眼：可以把推荐项放大、其余折叠。
- 改动都只影响之后新开的局；进行中的局别动，避免规则中途变。
