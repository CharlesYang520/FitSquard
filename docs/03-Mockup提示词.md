# FitSquad 瘦身战队 · Mockup 提示词 v0.9

> 与 `01-PRD-MVP.md`（PRD v0.9）、`mockup/SHARED-SPEC.md` 对齐；数值和假数据以 SHARED-SPEC 第 5 节为准。v0.8 及以前（积分押注版、19 页）见 `.backup/v0.8-2026-10-24/docs/03-Mockup提示词.md`。

## 1. 使用说明
把第 2 节全局规范 + 某一页的提示词一起交给设计工具（Figma AI / Midjourney / v0 等）或前端，生成 375×812 的微信小程序画板。每页只做一个主按钮；状态用多张画板表示。

## 2. 全局设计规范

**中文（v0.9 最终 · 碳白竞技）**：简单、醒目、有竞技感。页面底 #FAFAF8，纯白卡片配 1px 细线 #EEECE7，几乎不用阴影；碳黑 #141414 用于主文字、黑底白字主按钮和黑色头部（战队、战书、战报、AI 推荐卡、海报）；信号橙 #FF5A1F 只用于 AI 推荐标签、推荐卡打勾、主角数字和当前 tab，每屏不超过 2 处；大数字用衬线体。不用粗描边、硬投影、倾斜贴纸、荧光色和渐变；人物头像色降饱和。375×812 微信小程序，原生导航栏浅色底黑字（战队 / 战书 / 战报为黑底白字），右上胶囊区留空；底部 3 个 tab：今日 / 战队 / 我的，当前项信号橙。全部简体中文，只调侃行为不碰身体，不出现 kg、积分、押注（“我的”页私密体重卡除外）。

**English (final · Carbon)**: Simple, bold, competitive. Off-white #FAFAF8 background, white cards with 1px hairlines #EEECE7, almost no shadows. Carbon black #141414 for text, black primary buttons with white labels, and black header blocks. Signal orange #FF5A1F only for the AI-pick label, the pick's check button, hero numerals and the active tab — max two uses per screen. Serif display numerals. No thick outlines, hard shadows, tilted stickers, neon or gradients; desaturated avatar colors.

> 页面提示词中提到的“荧光绿”“贴纸”“黑描边硬投影”等描述一律按上面的碳白规范替换：荧光绿 → 信号橙（且只用在规定位置），贴纸 → 白卡细线，黑描边硬投影 → 1px 细线。

## 4. 交付检查
- 每页只有一个主按钮；一级页 3 个 tab；右上胶囊区空着。
- 没有积分、押注、奖池、身体档案、BMI、口令、上秤视频、好友榜、免断卡、盲盒、周称号等旧元素。
- kg 只出现在“我的”私密体重卡。
- 荧光绿每屏 ≤ 2 处；番茄红只用于调侃 / 警示。
- 文案只调侃行为。
