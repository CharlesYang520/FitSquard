## 0. 准备材料

- **个体工商户营业执照**：必须。个人主体小程序不开放社交类服务（战队、排名、队内动态都算），审核会被拒。线上办理：微信搜“个体工商户登记”或当地政务服务小程序，经营范围勾“健康咨询（不含医疗）/ 体育健身服务 / 软件开发 / 信息技术咨询”这类即可。
- 经营者身份证、本人实名并绑卡的微信（做管理员）。
- **一个从没注册过微信公众平台的邮箱**（公众号、小程序都没用过）。
- 名称备选 3 个：例如“瘦身战队”“瘦身战队打卡”“一起瘦战队”。可能撞名，名称设好后基本改不了。
- 头像：方形 PNG ≥ 144×144（可先用碳黑底白字“瘦”）。

## 1. 注册小程序 → 拿 AppID

1. 打开 https://mp.weixin.qq.com → 立即注册 → 选“小程序”。
2. 填邮箱、密码 → 去邮箱点激活链接。
3. 信息登记：主体类型选 **个体工商户**，填执照信息，管理员用微信扫脸。
4. 登录后台 → 左侧“开发与服务 / 开发管理 → 开发设置”，复制 **AppID(小程序 ID)**，形如 `wx1234abcd5678ef90`。

> **交给我：AppID。** AppID 不是秘密，可以直接发；**AppSecret 不用给我，也别发到群里**（云开发用不到）。

## 2. 微信认证

1. 后台“设置 → 基本设置 → 微信认证”（或首页提示“去认证”）。
2. 按页面填资料、付认证费（以页面金额为准），1–5 个工作日出结果。
3. 认证时会一起确认小程序名称，用准备好的备选名。

不认证没法备案，也没法上线；但开发和真机体验不受影响。

## 3. 名称、头像、简介、服务类目

1. “设置 → 基本设置”：填名称、头像、简介（如：熟人组队，每天 9 选 3 小行动，一起连续达标）。
2. “服务类目 → 添加”。在类目选择器里优先找**不需要额外资质**、贴合“运动健康打卡 + 小队排名”的类目。候选（按顺序试，选择器会提示是否要资质）：
   - 工具 > 健康管理
   - 体育 > 体育培训 / 运动健身相关
   - 生活服务 > 其他相关
3. 遇到要求“医疗 / 医疗器械 / 社交”资质的类目先别选。我们的产品不做诊疗、不做陌生人社交，文案也避免“减重 X 斤”“治疗”这类词。

> **交给我：类目页截图。** 订阅消息模板库按类目给，我据此确认 3 个模板能不能找到。

## 4. 开通云开发 → 拿云环境 ID

1. 下载安装 **微信开发者工具**（稳定版）：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 用管理员微信扫码登录 → “导入项目”：
   - 目录选：`/Users/cn-charlesyang/AI Native/02 life/FitSquad/app`
   - AppID 填第 1 步拿到的那个
3. 顶部工具栏点 **“云开发”** → 开通。
   - 套餐选 **免费体验版**：每个账号一个，按月给一定资源点，开发和种子期够用。
   - 环境名称：`fitsquad`。
4. 开通后在云开发控制台“设置 / 环境概览”复制 **环境 ID**，形如 `fitsquad-8gabc123def`。
5. 上线前再按用户量升级到“个人版”（具体价格看购买页）。不用提前买。

> **交给我：环境 ID。** 我填进 `app/src/config.ts`，并把 `project.config.json` 的 appid 改成你的。

## 5. 用户隐私保护指引（提审必填）

后台“设置 → 服务内容声明 → 用户隐私保护指引”，勾选并说明用途：

| 信息 | 用途写法 |
|---|---|
| 微信昵称、头像 | 用于在战队内展示你的身份 |
| 微信运动步数 | 用于“步数类”行动自动打卡，只记当天是否达到阈值 |
| 订阅消息 | 用于打卡提醒、队友提醒和战报通知（用户点击同意后才发） |

我们不收集手机号、性别、生日、身高；体重是第 3 步的可选私密记录，到时再补一行。

## 6. 小程序备案（上线必需）

1. 前提：已认证。后台“设置 → 基本设置 → 小程序备案”。
2. 填主体（个体户）、经营者身份证、手机号短信核验、小程序服务内容（选与类目一致的描述），按要求做人脸核验。
3. 平台初审 1–2 天，然后提交到通信管理局，一般 1–20 个工作日。备案期间可以继续开发和真机体验，只是不能发布。

## 7. 订阅消息模板（3 个）

类目确定后：后台“功能 / 基础功能 → 订阅消息 → 公共模板库”，类型选**一次性订阅**，搜下列关键词，选字段最接近的：

| 用途 | 搜索关键词 | 需要的字段（大致） |
|---|---|---|
| 明早提醒 | 打卡提醒 / 签到提醒 | 活动名称、提醒内容、时间 |
| 被队友催 | 待办提醒 / 打卡提醒 | 提醒人、提醒内容、时间 |
| 全员到齐 / 战报 | 活动结果通知 / 打卡结果通知 | 活动名称、结果、备注 |

选好后在“我的模板”里复制 **模板 ID**。找不到合适的就截图给我，我来挑替代字段。

> **交给我：3 个模板 ID**（第 3 步才用，不急）。
